# The Joke About The Demo

One line, one joke, about what it's like to build beside an AI coding agent and then stand next to the thing on stage.

## The joke

Rehearsal: my agent built the whole demo in four minutes. On stage: four minutes asking whether I was sure.

## Run

```
MAKEFUN_OUTPUT_DIR=/tmp/jout python3 -P -s main.py
```
